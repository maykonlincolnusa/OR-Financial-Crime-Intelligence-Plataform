# OR Financial Crime Intelligence Platform

Visão integrada dos projetos OR: ingestão, detecção, investigação, rastreamento, casos e produção de evidências auditáveis.

## MVP

- Catálogo dos módulos e contratos de integração.
- Fluxo demonstrável: dado sintético → alerta → caso → investigação.
- Identidade única para entidade, conta, transação, alerta e caso.
- Painel simples com volume, risco e status dos casos.

## Próximo passo

O pacote já agrega alertas independentes, preserva o módulo de origem e prepara a triagem. Próximo: integrar Simulator, Trace e Case Intelligence por contratos JSON versionados.
